# Site Commenter — расширение Chrome

Обёртка над клиентом из `src/`: content script монтирует окно замечаний в
shadow root страницы, снимок берётся нативный — `chrome.tabs.captureVisibleTab`.

## Сборка

```bash
npm install
npm run build:extension     # → extension/dist
```

Затем `chrome://extensions` → включить «Режим разработчика» → «Загрузить
распакованное» → выбрать `extension/dist`.

## Как это работает

- **content script** (`src/content.tsx`) проверяет `/api/v1/auth/me`, читает
  маршрут, канал и дату из URL и монтирует `UiCommentsProvider` +
  `UiCommentsWidget` в shadow root.
- **service worker** (`src/background.ts`) отдаёт снимок вкладки, открывает
  окно по кнопке на панели Chrome и `Alt+Shift+C`, показывает счётчик на
  иконке.
- **снимок** (`src/nativeCapture.ts`) скрывает панель на два кадра, снимает
  вкладку, переводит PNG в JPEG (снимок в 3–5 раз легче) и возвращает в модуль.
- **разметка** — тот же SVG-слой модуля, поэтому попадает на нативный снимок
  без склейки.

## Настройка под свой сервис

| Что | Где |
|---|---|
| Домены, на которых работает расширение | `manifest.json` → `content_scripts.matches` |
| Базовый путь API | `src/content.tsx` → `API_BASE` |
| Горячая клавиша | `manifest.json` → `commands` |

`captureVisibleTab` требует разрешения `<all_urls>` **или** `activeTab`.
В манифесте стоит `<all_urls>` в `host_permissions` — так снимок работает и
из плавающей кнопки, и из меню расширения. Если нужен минимальный набор прав,
уберите `<all_urls>` и открывайте окно только кнопкой на панели Chrome или
горячей клавишей: тогда `activeTab` выдаётся на текущую вкладку.

## Публикация

- **Chrome Web Store**: аккаунт разработчика ($5), загрузка ZIP из
  `extension/dist`, ревью обычно 1–3 дня. Обновления приходят автоматически.
- **Внутри компании**: политика `ExtensionSettings` в Chrome Enterprise
  (force-install по ID) или ручная установка распакованного в dev-режиме.
- Иконки: добавьте `icons` в манифест (16/32/48/128 PNG), если нужен свой
  значок; без них Chrome покажет стандартный.

## Ограничения

- Снимается активная вкладка и только видимая область.
- `captureVisibleTab` ограничен двумя вызовами в секунду — для ручного
  сохранения это не мешает.
- Расширение не ставит второй виджет на страницах, где уже есть встроенный
  модуль (метка `data-ui-comments-inline`).
