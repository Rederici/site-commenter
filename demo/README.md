# Демо

Страница для ручной проверки модуля и источник скриншотов в README.
Данные вымышленные, сервер не нужен: API модуля хранит замечания в памяти.

```bash
npm install
npm run demo          # сборка + сервер на http://127.0.0.1:5173
```

Или по шагам:

```bash
node demo/build.mjs
node demo/serve.mjs 4173
```

Что можно проверить:

- кнопка «Замечание» в правом нижнем углу;
- разметка: стрелка, подчёркивание, обводка, надпись, цвета, отмена и очистка;
- снимок видимой области вместе с разметкой;
- вкладка «Замечания» — реестр, статусы и ответ;
- после перезагрузки страницы замечания исчезают: они живут только в памяти.
